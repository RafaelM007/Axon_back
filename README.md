# Axon — Backend

Backend da plataforma **Axon**, uma aplicação mobile gamificada que incentiva foco, disciplina e evolução por meio de objetivos, grupos, validações e rankings.

Desenvolvido com **Node.js, Express e MongoDB**, o projeto disponibiliza uma API REST responsável pelas regras de negócio e pela comunicação entre o aplicativo e os serviços de dados.

## Tecnologias

* Node.js
* Express
* MongoDB Atlas e Mongoose
* JWT e Bcrypt
* Multer e Cloudinary
* Swagger
* Node-cron

## Funcionalidades

* Autenticação e gerenciamento de usuários.
* Criação e gerenciamento de grupos.
* Gerenciamento de objetivos e tarefas.
* Envio e validação de evidências.
* Sistema de contestação e votação.
* Ranking e pontuação.
* Processos automatizados para gerenciamento de votações.

## Organização do projeto

O backend possui uma estrutura modular, separando responsabilidades entre rotas, controllers, models, services, middlewares, configurações e tarefas automatizadas.
